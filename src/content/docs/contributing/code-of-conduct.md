---
title: Code of Conduct
description: Expectations for everyone participating in Kern's community.
---

Kern follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In practice: **be kind, be direct, assume good faith.** Review code, not people. Disagree with reasons. Welcome newcomers and help them land their first change.

Harassment, discrimination or personal attacks are not tolerated in issues, pull requests, chat, calls or any other project space.

## Reporting

Report unacceptable behaviour to **conduct@kern.dev**, or open a private security advisory on GitHub if you prefer that channel. Reports are handled confidentially by the maintainers.
