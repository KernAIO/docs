Three closely related modules cover knowledge, files and time.

## Docs (wiki)

Notion/Outline-style documentation:

- **Spaces** (collections) containing **nested pages**; per-space permissions.
- **Real-time collaboration** via Yjs through the `collab` service — multiple cursors, offline edits merge on reconnect.
- Comments and mentions, **embeds** of issues, files, other pages and diagrams, templates, **version history** with restore, publish to a public link, export to Markdown/PDF, full-text search.
- Whiteboards are *v1.x*.

Rich text is Tiptap 3 everywhere in Kern (issue descriptions, comments, docs), so the editor — and its collaboration layer — is shared. The server side is described in [Collab protocol](/developers/collab-protocol/).

## Drive

- Folders and files, **resumable uploads** (tus), file **versions**, trash/restore, per-workspace quotas.
- **Share links** with expiry and password; link files to any object (issue, candidate, deal).
- Previews for images, video and PDF out of the box; office documents when the `preview` profile (Gotenberg) is enabled.
- Files are stored in S3/MinIO with presigned GET URLs; thumbnails are generated by the worker.
- WebDAV (read-only) is *v1.x*.

## Calendar

- Personal and team calendars; events (all-day, recurring), reminders, a call link per event.
- **Overlays** from other modules: sprints, leaves, interviews — so the calendar is a view over the workspace, not another silo.
- ICS export. CalDAV and Google sync are *v1.x*.
