**Planned. Neither module is in a release yet, and no code for either exists in the repositories.**

Kern's wiki used to be described on this page. It is now its own module, **Quire**, and it is
built — see [Quire](/modules/quire/).

## Drive

- Folders and files, **resumable uploads** (tus), file **versions**, trash/restore, per-workspace
  quotas.
- **Share links** with expiry and password; link files to any object (issue, candidate, deal).
- Previews for images, video and PDF; office documents when the `preview` profile (Gotenberg) is
  enabled.
- Files stored in S3/MinIO with presigned GET URLs; thumbnails generated by the worker.
- WebDAV, read-only.

## Calendar

- Personal and team calendars; events (all-day, recurring), reminders, a call link per event.
- **Overlays** from other modules: sprints, leaves, interviews — so the calendar is a view over the
  workspace rather than another silo.
- ICS export, then CalDAV and Google sync.

Kern already stores files. Uploading to S3/MinIO and fetching a presigned download URL are part of
the platform rather than of a module, and they work today. Drive is the module that would put a
browsable folder tree, versions and share links on top of them.
